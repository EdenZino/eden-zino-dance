# Eden Zino v1.8.0 — Relative Media + Accessibility

## מדיה

- `uploaded_assets.object_key` הוא מקור האמת עבור קבצי R2.
- כל Upload חדש מחזיר URL יחסי ולא URL שתלוי בדומיין.
- Migration 0010 ממיר כתובות `/api/media` היסטוריות ל-relative URLs.
- נוספה בדיקת R2 Integrity מתוך ממשק הגלריה.
- בדיקת Integrity מציגה object keys שחסרים ב-Bucket של הסביבה הפעילה.

## בטיחות פריסה

- `npm run deploy` הוסר.
- נוספו `npm run deploy:dev` ו-`npm run deploy:prod` בלבד.
- ה-Workflows הקיימים ממשיכים לפרוס עם environment מפורש.

## נגישות

- נוספה הצהרת נגישות v2026-07-17 בעברית ובאנגלית.
- סעיף פטור אינו מפורסם ללא בדיקה.
- פרטי קשר לנגישות ומגבלות ידועות ניתנים לעריכה בהגדרות.
- לכל סדנה נוספו פרטי נגישות פיזיים עם מצב UNKNOWN כברירת מחדל.
- נוספו Focus Trap ו-Escape לחלונות ציבוריים מרכזיים.
- שופרו `aria-live`, הודעות שגיאה, labels ושמות נגישים.
- נשמר Skip Link, ניווט מקלדת ו-`prefers-reduced-motion`.
- שופרה ניגודיות טקסט משני וטקסטי accent קטנים.
- אין חסימת Zoom בדפדפן.
- נוספה `npm run validate:static` לבדיקת safeguards קבועים.

## Production gate

Production readiness נחסם כאשר:

- מסמך ACCESSIBILITY לא אושר ב-OWNER.
- חסרים איש קשר/דוא"ל/טלפון/כתובת לנגישות.
- טרם הוזן מידע אמיתי על מגבלות נגישות ידועות.

חוסר בתרגום אנגלי לכתובת/מגבלות מוצג כאזהרה.

## מגבלה חשובה

v1.8 משפר ומאמת את הקוד מול המדיניות שסופקה, אך אינו מהווה בדיקת נגישות מקצועית מלאה או אישור תקן. בדיקת Production עם טכנולוגיות מסייעות ותוכן אמיתי עדיין נדרשת לפני טענה כזו.
