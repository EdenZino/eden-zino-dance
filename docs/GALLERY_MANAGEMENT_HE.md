# ניהול גלריית תמונות וסרטונים — גרסה 1.5.0

## מה נוסף

המערכת כוללת כעת גלריה ציבורית מלאה המחוברת ל־Cloudflare R2 ולמסד הנתונים:

- העלאת תמונות וסרטונים מתוך ממשק הניהול.
- פרסום מיידי או שמירה כטיוטה.
- כותרת, כיתוב ותיאור נגיש לכל פריט.
- שליטה בסדר התצוגה.
- הצגה ישירה של תמונות וסרטונים באתר.
- תצוגת Lightbox מוגדלת.
- ניגון וידאו עם תמיכה ב־HTTP Range Requests.
- עריכת מטא־דאטה לאחר ההעלאה.
- הסתרה זמנית בלי למחוק את הקובץ.
- מחיקה לצמיתות מהמסד ומ־R2.
- Audit Log לפעולות יצירה, עדכון ומחיקה.

## איפה מנהלים

```text
ניהול → גלריה
```

## פורמטים ומגבלות

תמונות:

- JPEG
- PNG
- WebP
- GIF
- AVIF
- עד 12MB לקובץ

סרטונים:

- MP4
- WebM
- עד 80MB לקובץ

MOV לא מתקבל בכוונה. התמיכה שלו בדפדפנים אינה אחידה, ולכן הוא אינו מתאים לגלריה שאמורה לעבוד ישירות ב־Chrome, Android ו־Windows. יש להמיר ל־MP4 או WebM לפני ההעלאה.

## תיאור נגיש

לכל תמונה יש למלא תיאור שמסביר בקצרה מה רואים. לדוגמה:

```text
עדן מדגימה רצף תנועה לקבוצת מתחילים בסטודיו.
```

בסרטון התיאור משמש כ־ARIA label וכמידע מסייע. הוא אינו מחליף כתוביות בסרטון כאשר יש בו דיבור מהותי.

## פרסום והסתרה

- `מוצג באתר` מסומן: הפריט מוצג בדף הגלריה ובתצוגה המקדימה בדף הבית.
- `מוצג באתר` אינו מסומן: הקובץ נשאר ב־R2 ובממשק הניהול, אבל אינו חשוף באתר הציבורי.

## סדר תצוגה

מספר נמוך יותר מופיע קודם. כאשר לשני פריטים אותו מספר, החדש יותר מופיע קודם.

דוגמה:

```text
0  — פריט ראשון
10 — פריט שני
20 — פריט שלישי
```

## מחיקה

לחיצה על `מחיקה` מבצעת:

1. מחיקה מטבלת `uploaded_assets`.
2. מחיקה אוטומטית מטבלת `gallery_items` באמצעות Cascade.
3. מחיקת האובייקט מדלי R2.
4. שמירת Audit Log.

הפעולה אינה ניתנת לביטול. כאשר רק רוצים להוריד פריט זמנית מהאתר, יש לבטל את הסימון `מוצג באתר` ולא למחוק אותו.

## מיגרציה

לפני הפריסה יש להריץ:

```bash
export DATABASE_URL='מחרוזת-החיבור-של-Neon'
npm run migrate
```

המיגרציה החדשה היא:

```text
db/migrations/0007_gallery_library.sql
```

## פריסה

```bash
npm ci
npm run validate
npm run migrate
npm run deploy
```

## הערת אחסון

סרטונים צורכים נפח ותעבורה מהר יותר מתמונות. אין להעלות קובצי מקור כבדים מהטלפון ללא דחיסה. עבור גלריה שיווקית, MP4 בקידוד H.264 וב־1080p הוא בדרך כלל בחירה מעשית יותר מקובץ 4K כבד.
