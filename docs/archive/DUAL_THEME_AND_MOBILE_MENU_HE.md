# שני עיצובים ותפריט מובייל — גרסה 1.3.0

## בחירת העיצוב

בממשק הניהול:

1. היכנסו אל **הגדרות**.
2. תחת **עיצוב האתר הציבורי** בחרו:
   - **Classic** — העיצוב המקורי והגרפי.
   - **Modern** — העיצוב הצילומי והעדכני.
3. ניתן לפתוח תצוגה מקדימה של כל עיצוב בחלון חדש.
4. לחצו **שמירת הגדרות**.

השינוי נשמר במסד הנתונים בשדה `business_settings.public_theme` ומוחל באתר ללא Build או Deploy נוסף.

שני העיצובים משתמשים באותם רכיבים עסקיים, API ומסד נתונים. אין שכפול של מנגנוני הרשמה, קיבולת, תשלום או אזור לקוח.

## מעבר מגרסה 1.2.0

לפני הפריסה הריצו:

```bash
npm ci
npm run migrate
npm run deploy
```

המיגרציה `0005_dual_public_themes.sql` מוסיפה את הגדרת העיצוב. ברירת המחדל היא `CLASSIC`.

## תצוגה מקדימה ישירה

לבדיקה מבלי לשנות את ההגדרה הפעילה:

```text
https://YOUR-DOMAIN/?theme=classic
https://YOUR-DOMAIN/?theme=modern
```

פרמטר התצוגה המקדימה משפיע על חלון הדפדפן הנוכחי בלבד ואינו משנה את מסד הנתונים.

## תיקון תפריט המובייל

התפריט הציבורי אינו נמצא עוד בתוך ה־Header. הוא נוצר באמצעות React Portal ישירות תחת `document.body`.

הסיבה: `backdrop-filter` ו־Sticky Header עלולים ליצור ב־Chrome וב־iOS containing block חדש, שגורם ל־`position: fixed` בתוך ה־Header להיחתך או להתכווץ.

המימוש החדש כולל:

- גובה `100dvh` אמיתי.
- רוחב `min(88vw, 380px)` ורוחב מלא עד 380px.
- `flex-shrink: 0`.
- גלילה אנכית פנימית.
- קישורים ברוחב מלא ובגובה מגע של לפחות 44px.
- Focus Trap.
- סגירה באמצעות Escape, כפתור סגירה, לחיצה על הרקע או בחירת קישור.
- החזרת ה־Focus לכפתור שפתח את התפריט.
- תמיכה ב־Safe Area.

## בדיקה שבוצעה
