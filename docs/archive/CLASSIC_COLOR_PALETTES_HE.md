# פלטות צבעים ל־Classic — גרסה 1.4.0

## מה נוסף

עיצוב `Classic` תומך כעת בחמש פלטות צבעים מוכנות. בחירת הפלטה נשמרת במסד הנתונים ומשפיעה על האתר הציבורי מיד, ללא Build או Deploy נוסף.

הפלטה משנה את מערכת העיצוב המלאה של Classic:

- רקע האתר והכרטיסים.
- צבעי טקסט וטקסט משני.
- אזורי הבמה הכהים.
- כפתורים, קישורים, Focus והדגשות.
- כרטיסי סדנה, Hero, אזור המדריכה ותפריט המובייל.

היא אינה משנה את `Modern`, את ממשק הניהול או את הלוגיקה העסקית.

## הפלטות

| מזהה | שם | אופי |
|---|---|---|
| `ROSIN` | Rosin | ורוד־יין, ענבר ופודרה חמה. ברירת המחדל והגרסה הקרובה ביותר ל־Classic המקורי. |
| `PLUM` | Plum | שזיף עמוק, זהב ורקע פנינה. |
| `OCEAN` | Ocean | טורקיז כהה, קורל וזהב רך. |
| `SAGE` | Sage | ירוק מרווה, טרקוטה וחול. |
| `MIDNIGHT` | Midnight | כחול לילה, סגול וזהב. |

## בחירה בממשק הניהול

1. היכנסו אל **ניהול → הגדרות**.
2. תחת **עיצוב האתר הציבורי** בחרו `Classic`.
3. תחת **פלטת הצבעים של Classic** בחרו את הפלטה הרצויה.
4. ניתן לפתוח תצוגה מקדימה של כל פלטה בחלון חדש.
5. לחצו **שמירת הגדרות**.

הבחירה נשמרת בשדה:

```text
business_settings.classic_palette
```

## תצוגה מקדימה ללא שמירה

ניתן לפתוח ישירות:

```text
/?theme=classic&palette=rosin
/?theme=classic&palette=plum
/?theme=classic&palette=ocean
/?theme=classic&palette=sage
/?theme=classic&palette=midnight
```

פרמטרי ה־Preview אינם משנים את ההגדרה הפעילה במסד.

## שדרוג מסד הנתונים

לאחר העתקת גרסה 1.4.0 יש להריץ:

```bash
export DATABASE_URL='מחרוזת-החיבור-של-Neon'
npm run migrate
```

המיגרציה החדשה:

```text
db/migrations/0006_classic_color_palettes.sql
```

ברירת המחדל היא `ROSIN`. המיגרציה כוללת Constraint שמונע שמירת שם פלטה לא חוקי.

## נגישות

צבעי הטקסט הראשיים, הטקסט המשני וההדגשות בכל חמש הפלטות נבחרו כך שיעמדו ביחס ניגודיות של לפחות 4.5:1 מול רקע הקריאה העיקרי. עדיין נדרשת בדיקה ידנית לאחר העלאת תמונות ותוכן אמיתיים, משום שטקסט המופיע מעל תמונה תלוי גם בתמונה עצמה.
