# דוח אימות גרסה 1.7

## בדיקות שבוצעו בסביבת העריכה

- כל 34 קבצי TypeScript/TSX עברו parsing באמצעות TypeScript ללא שגיאות תחביר.
- מעבר סטטי על ה-Frontend הציבורי לא מצא מחרוזות עבריות לא עטופות במנגנון השפה.
- נבדקו התאמות מספר העמודות/ערכים בפקודות SQL המרכזיות ליצירת/שכפול/סדרת סדנאות.
- בוצעה בדיקת מיתוג ולא נמצאו שימושים ציבוריים ב-`Eden Zino Dance`; שם המותג הציבורי הוא `Eden Zino`.
- נבדקו קישורי favicon, metadata ו-`WebSite` JSON-LD ב-`index.html`.
- נבדק שלא נשארו הפניות לקבצי הקונפיגורציה שנמחקו.

## בדיקת Build מלאה

בסביבת העריכה הנוכחית התקנת `npm ci` נתקעה ב-timeout מול Registry החבילות של סביבת העריכה לפני שהתקבלו כל החבילות הדרושות, ולכן לא היה ניתן להריץ כאן Build נקי מלא לאחר השדרוג. זו מגבלת סביבת הבנייה ולא תוצאה של שגיאת Build שנצפתה.

לכן **אין לסמן את גרסה 1.7 כמאומתת ל-Production עד ש-`npm run validate` עובר ב-GitHub Actions או ב-Codespaces שלך**.

הוספתי ל-`scripts/validate.mjs` בדיקות חדשות לגרסה 1.7:

- טעינת Migration 0009.
- קיום שדות English ו-`preferred_language`.
- שם עסק `Eden Zino`.
- ברירות מחדל באנגלית לדף הבית.
- שמירת שפת הרשמה `en`.
- חסימת שפה שאינה `he` או `en`.

כך ה-Workflow הקיים יעצור את הפריסה אם המיגרציה הדו-לשונית אינה תקינה.
