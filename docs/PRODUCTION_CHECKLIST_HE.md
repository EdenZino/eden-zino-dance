# Checklist לפני הפעלה מסחרית — 1.2.0

## סודות ותשתית

- [ ] סיסמת Neon סובבה כאשר הופיעה אי פעם בקובץ דוגמה או Repository.
- [ ] אין `.env`, `.dev.vars`, Tokens או Connection Strings ב־Git.
- [ ] ארבע המיגרציות הורצו במסד הייצור.
- [ ] R2 production ו־preview קיימים.
- [ ] Rate Limit bindings מזוהים ב־Wrangler dry-run.
- [ ] Turnstile Site Key ו־Secret מוגדרים ונבדקו.
- [ ] `SESSION_SECRET`, `SETUP_TOKEN` ו־`CRON_SECRET` אקראיים ושונים.
- [ ] MFA פעיל בחשבונות Cloudflare, Neon, GitHub, PayMe ודוא״ל.

## מנהלים

- [ ] OWNER ראשון נוצר.
- [ ] OTP מגיע לדוא״ל.
- [ ] חמישה ניסיונות שגויים נועלים את החשבון.
- [ ] איפוס סיסמה מגיע ופועל פעם אחת בלבד.
- [ ] Sessions ישנים מתבטלים לאחר איפוס.
- [ ] VIEW_ONLY אינו משנה נתונים.
- [ ] INSTRUCTOR אינו משלים החזרים או מאשר מסמכים.

## PayMe

- [ ] מסוף Sandbox פעיל.
- [ ] תשלום מוצלח ונכשל נבדקו.
- [ ] Callback כפול אינו מאשר פעמיים.
- [ ] Secret או סכום שגויים נדחים.
- [ ] סגירת הדפדפן לפני Return אינה פוגעת באישור Callback.
- [ ] מקדמה ויתרה נבדקו.
- [ ] החזר מלא נבדק מול PayMe.
- [ ] החזר חלקי נבדק מול PayMe.
- [ ] ניסיון החזר כפול נחסם.
- [ ] Retry לאחר timeout אינו יוצר החזר כפול.
- [ ] סביבת הייצור אינה מצביעה ל־Sandbox.

## ביטול, העברה ו־Waitlist

- [ ] ביטול מחזיר קרדיט כרטיסייה/מנוי.
- [ ] סטטוס נשאר `REFUND_PENDING` עד השלמת הכסף.
- [ ] כל החזר מתועד עם מזהה ספק.
- [ ] ביטול חוזר אינו יוצר פעולה כפולה.
- [ ] הבא ברשימת ההמתנה מוזמן פעם אחת.
- [ ] הזמנת Waitlist שומרת קיבולת ופוקעת בזמן.
- [ ] העברה לסדנה מלאה נחסמת.
- [ ] העברה במחיר שונה נחסמת.
- [ ] שני ניסיונות למקום האחרון אינם גורמים ל־Overbooking.
