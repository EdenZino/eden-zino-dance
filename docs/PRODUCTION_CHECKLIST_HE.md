# Checklist לפני הפעלה מסחרית

## חסימות Go-Live

- [ ] פרטי העסק המלאים הוזנו בממשק הניהול.
- [ ] מסמכי TERMS, PRIVACY, CANCELLATION ו-ACCESSIBILITY אינם בגרסת DRAFT.
- [ ] עורך דין בדק את נוסח הביטולים, הפרטיות וההסכמות לסוג הסדנאות בפועל.
- [ ] רואה חשבון אישר את סוג המסמך החשבונאי ואת מועד הפקתו.
- [ ] הוגדרה מדיניות שמירת מידע ומחיקה.
- [ ] הוגדר ספק סליקה אמיתי ובוצעה עסקת בדיקה במסוף המיועד.
- [ ] נבדק Notify מוצלח, נכשל, כפול, חסר ובסכום שגוי.
- [ ] הוגדר ספק קבלות/חשבוניות ונבדק מסמך תקין.
- [ ] הוגדר דומיין דוא"ל מאומת ונבדקה מסירה ל-Gmail ול-Outlook.
- [ ] הסיסמאות והסודות נשמרים רק ב-Cloudflare Secrets.
- [ ] MFA מופעל בחשבונות Cloudflare, Neon, GitHub, סליקה, דוא"ל וחשבוניות.
- [ ] גיבוי ושחזור של Neon נוסו בפועל.
- [ ] בוצעה בדיקת נגישות מקלדת, קורא מסך, ניגודיות ו-Mobile.
- [ ] הועלו רק תמונות וטקסטים שהעסק רשאי לפרסם.

## תרחישי עסקה וקיבולת

- [ ] שני לקוחות מנסים לקנות את המקום האחרון בו-זמנית; רק אחד מצליח.
- [ ] מקום נעול משתחרר לאחר פקיעת זמן התשלום.
- [ ] רענון עמוד הצלחה אינו יוצר תשלום נוסף.
- [ ] Notify כפול אינו יוצר שתי עסקאות או שתי זכאויות.
- [ ] סכום Notify שונה מסכום ההרשמה נדחה.
- [ ] קופון מוגבל אינו חורג ממכסת השימוש.
- [ ] Early Bird מתחלף בזמן הנכון לפי Asia/Jerusalem.
- [ ] מקדמה ותשלום מלא מחושבים נכון לכמה משתתפים.
- [ ] יתרה משולמת רק על ההפרש שנותר.
- [ ] רשימת המתנה עובדת כאשר הסדנה מלאה.
- [ ] הזמנת המתנה שפגה אינה שומרת מקום.
- [ ] העברה לסדנה אחרת נחסמת כשאין מקום.
- [ ] הגבלת הרשמות לטלפון ולהזמנה עובדת.
- [ ] כרטיסייה מפחיתה קרדיטים פעם אחת בלבד.
- [ ] מנוי שפג אינו מאשר הרשמה.

## החזרים, ביטולים ופרטיות

- [ ] ביטול מצד העסק וביטול מצד הלקוח מתועדים בנפרד.
- [ ] החזר מלא וחלקי תואמים לעסקה אצל ספק הסליקה.
- [ ] לא מסמנים REFUNDED לפני שהכסף הוחזר בפועל.
- [ ] בקשת עיון ניתנת לאיתור ולסגירה.
- [ ] אנונימיזציה אינה מוחקת רשומות חשבונאיות שחובה לשמור.
- [ ] Retention נוסה על נתוני בדיקה בלבד לפני הפעלה בייצור.

## הרשאות ואבטחה

- [ ] VIEW_ONLY אינו משנה נתונים.
- [ ] INSTRUCTOR יכול לסמן נוכחות אך לא לשנות הגדרות או להשלים החזר.
- [ ] רק OWNER מנהל משתמשים, הגדרות עסק ופעולות רגישות.
- [ ] משתמש מנהל שעזב הושבת מיד.
- [ ] קובצי תמונה מוגבלים לסוג ולגודל.
- [ ] Cookie מנהל הוא HttpOnly, Secure ו-SameSite.
- [ ] הוגדר Cloudflare WAF/Rate Limiting עבור Login, Reserve ו-Notify.
- [ ] Audit Log נבדק ואינו ניתן לעריכה דרך ה-UI.
- [ ] בוצעה בדיקת חדירה או לכל הפחות סקר אבטחה לפני השקת קמפיין גדול.

## תפעול

- [ ] תזכורת נשלחת פעם אחת בלבד.
- [ ] תזכורת יתרה נשלחת במועד שהוגדר.
- [ ] כשל דוא"ל/WhatsApp מנסה שוב ואינו מפיל את העסקה.
- [ ] קיים תהליך שירות לקוחות לביטול, החזר והעברה.
- [ ] נבדק Export מול הנהלת חשבונות.
- [ ] נבדק דוח חלוקת הכנסות למדריכים.
- [ ] אדם מוגדר אחראי לטיפול בבקשות פרטיות ובאירועי אבטחה.
- [ ] קיים דף סטטוס/נוהל ידני למקרה שספק הסליקה או הדוא"ל מושבת.
